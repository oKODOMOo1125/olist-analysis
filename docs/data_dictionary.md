# Data dictionary: ตาราง `clean` (ผลของ `cleaning.clean_orders`)

1 แถว = 1 ออเดอร์ (ทุกสถานะ) · ค่าว่างในคอลัมน์วันที่ = ขั้นนั้นยังไม่เกิด

| คอลัมน์ | ความหมาย | ประเภท | ระดับ | ทำอะไรได้ | ระวัง |
|---|---|---|---|---|---|
| `order_id` | รหัสออเดอร์ | categorical | nominal | นับ, นับไม่ซ้ำ, join | ไม่ซ้ำ ใช้เป็นหน่วยของตาราง |
| `customer_id` | รหัสลูกค้าต่อออเดอร์ | categorical | nominal | join กับตาราง customer | เปลี่ยนทุกออเดอร์ ห้ามใช้นับคน ใช้ `customer_unique_id` แทน |
| `order_status` | สถานะล่าสุดของออเดอร์ (8 แบบ) | categorical | nominal | นับ, สัดส่วน, groupby | ไม่สะอาด 100%: canceled 6 ออเดอร์มีวันส่งถึง, delivered 8 ออเดอร์ไม่มีวันส่งถึง |
| `order_purchase_timestamp` | เวลาที่ลูกค้าสั่ง | numeric (เวลา) | interval | ลบกัน, เรียง, แบ่งเป็นเดือน | ข้อมูลหยุดราว ต.ค. 2018 ออเดอร์ช่วงท้ายยังเห็นไม่ครบ (right-censoring) |
| `order_approved_at` | เวลาที่การชำระเงินผ่าน | numeric (เวลา) | interval | ลบกัน, เรียง | ว่าง 160 ออเดอร์ |
| `order_delivered_carrier_date` | เวลาที่ส่งของให้ขนส่ง | numeric (เวลา) | interval | ลบกัน, เรียง | ว่าง 1,783 · มี 23 ออเดอร์ที่มาหลังวันที่ลูกค้าได้ของ |
| `order_delivered_customer_date` | เวลาที่ลูกค้าได้ของ | numeric (เวลา) | interval | ลบกัน, เรียง | ว่าง 2,965 = ยังไม่ถึงหรือไม่เคยส่ง |
| `order_estimated_delivery_date` | วันที่สัญญาว่าจะส่งถึง | numeric (เวลา) | interval | เทียบกับวันส่งถึง | เวลาเป็น 00:00 ทุกแถว สัญญาเป็นวัน จึงต้องเทียบแบบวันต่อวัน |
| `delivery_days` | วันที่รอ นับจากสั่งถึงได้ของ (มีทศนิยม) | numeric ต่อเนื่อง | ratio | ทุกอย่าง | เบ้ขวา รายงานมัธยฐานคู่เสมอ · ว่างถ้ายังไม่ส่ง |
| `days_late` | วันที่ได้ของ ลบ วันที่สัญญา (จำนวนเต็ม) | numeric ไม่ต่อเนื่อง | interval | ลบ, เฉลี่ย, เรียง | ติดลบ = ถึงก่อนกำหนด · 0 = ตรงวัน ไม่ใช่ "ไม่มี" · ส่วนใหญ่ติดลบราว 12 วัน |
| `delivery_status` | ป้ายจาก `days_late` | categorical | ordinal | นับ, เรียง | ข้อมูลหายตอนตัดช่วง (ช้า 8 กับ 180 วันได้ป้ายเดียวกัน) · `late_8d_plus` จริง ๆ คือมากกว่า 7 |
| `is_date_error` | วันที่เรียงลำดับแบบเป็นไปไม่ได้ | binary | nominal | ค่าเฉลี่ย = สัดส่วน | เป็นธง ไม่ได้ลบทิ้ง · True 23 ออเดอร์ |
