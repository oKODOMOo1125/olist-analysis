## 2026-11-03 · ออเดอร์ช่วงท้ายของข้อมูลยังเห็นไม่ครบ (right-censoring)

- **เจออะไร:** อัตราออเดอร์ที่ส่งนานเกิน 100 วันเป็น 0% ในเดือน 2018-07 และ 2018-08 ขณะที่เดือนอื่นอยู่ที่ 0.01–0.47%
- **ทำไม:** วันที่สั่งซื้อล่าสุดในข้อมูลคือ [วันที่] ออเดอร์ที่ยังไม่ถึงมือลูกค้าเป็น NaN และหลุดออกจากตัวหาร เดือนท้าย ๆ จึงเหลือแต่ออเดอร์ที่ส่งเร็ว
- **หลักฐาน:** `notebooks/02_python.ipynb` เซลล์อัตรารายเดือน
- **ผลต่องาน:** ห้ามสรุปว่าช่วงท้ายส่งเร็วขึ้น ใช้เฉพาะออเดอร์ที่สั่งก่อน 2018-09-01 และระวังเดือนท้าย ๆ ในขอบเขตด้วย
- **ไปอยู่ที่:** README > Limitations

## 2026-11-03 · Olist ตั้งวันที่สัญญาส่งไว้เผื่อมาก

- **เจออะไร:** มัธยฐานของ `days_late` คือ −12 ออเดอร์ส่วนใหญ่ถึงก่อนวันที่สัญญาราว 12 วัน
- **หลักฐาน:** `clean[["days_late"]].describe()`
- **ผลต่องาน:** "ตรงเวลา" ตามวันที่สัญญา ไม่ได้แปลว่าเร็ว ต้องรายงานคู่กับ `delivery_days`
- **ไปอยู่ที่:** README > Key findings
